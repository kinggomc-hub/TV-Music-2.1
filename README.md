# 가사 플레이어 N (네이티브 시험판 v0.2)

웹뷰(HTML) 대신 **안드로이드 자체 기술**로 만든 TV 박스용 가사 플레이어입니다.
웹뷰 버전(`com.lyricplayer.tv`)과 앱 ID 가 달라서 **나란히 설치해 비교**할 수 있습니다.

| 부분 | 기술 | 이유 |
|---|---|---|
| 소리 | ExoPlayer (androidx.media3) | 화면과 별개 스레드. 화면이 느려져도 소리는 영향받지 않음. mp3/flac/m4a/aac/wav/ogg/opus 재생 |
| 배경·가사 화면 | OpenGL ES 2.0 (`GLSurfaceView`) | 가사는 줄이 바뀔 때만 글자를 이미지로 만들고, 이후 GPU 가 이동·확대·투명도만 처리 |
| 해상도 | `SurfaceHolder.setFixedSize` | **720p(기본) 또는 1080p**로 그린 뒤 TV 해상도로 늘려 보여 줌 |
| 프레임 | 33ms 마다 한 번 그리기 | **30fps 제한** |
| 메뉴 | 일반 안드로이드 View | 리모컨 방향키로 이동 |
| USB | 마운트된 USB/SD 경로(`/storage/XXXX`)를 직접 읽음 | 파일 관리자 앱 불필요 |

> ⚠ **이 프로젝트는 안드로이드 SDK 가 없는 환경에서 작성되어 APK 로 빌드해 실기기에서 실행해 보지는 못했습니다.**
> 확인한 것: 자바 문법·타입 검사(안드로이드 API 를 흉내 낸 스텁에 대해), LRC 읽기와 효과 선택 규칙 실행 시험, 모든 셰이더의 컴파일·렌더(WebGL, GLSL ES 1.0).
> 확인하지 못한 것: 실제 안드로이드 컴파일, 박스에서의 프레임·소리·메뉴 동작. 첫 빌드에서 오류가 나면 메시지를 알려 주세요.

## 1. APK 만들기 (웹뷰 버전과 같은 방법)

**GitHub Actions**: 이 폴더의 **내용물**(`app`, `gradle`, `.github`, `build.gradle`, `settings.gradle`, `gradle.properties`)을 새 저장소 맨 위에 올리고 **Actions → Build APK → Run workflow**. 끝나면 **Artifacts → LyricPlayerNative-apk**.
(`.github` 폴더가 업로드에서 빠지면 `.github/workflows/build-apk.yml` 파일을 웹에서 직접 만들어 붙여 넣으세요.)

**Android Studio**: 폴더를 열고 **Build → Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk`

설치: `adb install -r app-debug.apk` 또는 USB 메모리에 담아 박스에서 설치.

## 2. 사용법
- 앱을 켜면 USB 를 자동으로 검색하고 **랜덤 재생**을 시작합니다(설정에서 끌 수 있음). 저장소 권한 창이 뜨면 허용하세요.
- 음악과 **같은 이름의 .lrc(또는 .txt)** 가 같은 폴더에 있으면 가사가 붙습니다. 가사 파일은 UTF-8 또는 EUC-KR(CP949) 모두 읽습니다.
- 가사가 없거나 첫 가사가 늦게 시작하면 그동안 **곡 제목**이 가사 줄처럼 표시됩니다.

### 리모컨
| 상황 | 키 | 동작 |
|---|---|---|
| 재생 화면 | ◀ / ▶ | 이전 / 다음 곡 |
| | ▲ / ▼ | 하단 컨트롤 열기 (이전·재생/정지·다음·목록·설정·종료) |
| | 확인 | 재생 / 일시정지 |
| | 메뉴(≡) | 설정 열기 |
| | 뒤로 | 한 번: 안내 → 2.5초 안에 한 번 더: 종료 |
| 컨트롤·목록·설정 화면 | 방향키 / 확인 | 항목 이동 / 선택 (체크 상자는 켜기·끄기) |
| | 뒤로 | 한 단계씩 닫기 |
| 어디서나 | 미디어 키 | 재생/정지, 다음/이전 곡, 빨리감기·되감기(±20초, 길게 ±60초), CH+/CH- = 다음/이전 곡 |

## 3. 효과 구성 (모두 설정에서 켜고 끌 수 있음, 기본 전부 켜짐)
**한 곡 안에서는 효과가 고정**되고, 곡이 바뀔 때마다 새로 랜덤으로 고릅니다. 같은 효과도 곡 제목에서 정한 **색·속도·위치**가 달라 곡마다 다르게 보입니다.

**배경 (곡마다 1개, 최근 3곡에서 쓴 것은 피함, 총 16종)**
- 가벼운 편: 별 반짝임(80개) · 느리게 오르는 먼지 점(30개) · 가끔 지나가는 유성 · 은은한 가로 파동선 · 테두리 어둠이 숨 쉼 · 숨 쉬는 빛 · 공전하는 빛
- 중간: 떠다니는 빛 덩어리 · 오로라 커튼 · 노을빛 띠 · 안개 흐름 · 스포트라이트 스윕 · 대각선 리본 · 흐르는 그라데이션 · 지나가는 빛줄기
- 가장 무거울 것으로 예상: **깊이감 빛 덩어리**(빛 덩어리 두 겹)
- 모든 배경 밑에는 곡마다 색이 다른 정지 그라데이션이 깔립니다. (점·격자 같은 패턴 배경은 뺐습니다.)

**가사가 나타나는 효과 (곡마다 2~3개를 줄마다 섞음, 같은 효과 연속 금지, 0.45초 이하, 총 19종)**
- 줄 단위(14종): 아래에서 떠오름 · 위에서 내려옴 · 커지며 나타남 · 줄어들며 나타남 · 옆에서 짧게 밀려옴(방향은 곡마다 고정) · 왼→오른쪽 / 오른→왼쪽 / 아래→위 / 위→아래 드러남 · 가운데서 양옆으로 열림 · 살짝 기울었다 바로잡힘 · 대각선으로 살짝 들어옴 · 가로로 펼쳐짐 · 세로로 펼쳐짐
- 단어/글자 단위(5종): 단어가 차례로 나타남 · 단어가 위에서 차례로 내려옴 · 글자가 차례로 밀려옴 · 글자가 아래에서 차례로 떠오름 · 가운데서 바깥으로 퍼짐
- 한 곡의 2~3개에는 줄 단위 효과가 항상 하나 이상 들어갑니다.

**가사가 사라지는 효과 (곡마다 1개, 0.22~0.24초, 5종)**: 서서히 투명 · 위로 올라가며 사라짐 · 작아지며 사라짐 · 옆으로 밀리며 사라짐 · 커지며 사라짐

**강조 장식 (가끔: 약 5~6줄에 한 번, 최소 3줄 간격, 첫 2줄 제외, 한 줄에 단어 하나, 3종)**: 흰 박스 반전 · 단어 밑줄 · 단어 살짝 크게 (단어 테두리 박스는 뺐습니다.)

**뺀 것**: 위아래 조각이 맞물림, 잔상이 합쳐짐, 고리, 단어 테두리 박스, 패턴 배경, 실시간 블러, 입자 수백 개, 소리에 반응하는 효과.

### v0.2 에서 바뀐 점
- **하단 상시 표시**: 곡 시작 때 제목을 가사 줄처럼 보여 주던 것을 없애고, 재생 중 화면 하단에 `제목 - 가수명`을 계속 표시합니다(프레임 표시보다 조금 큰 20sp). 파일 태그(ID3 등)에서 읽고, 태그가 없으면 파일 이름이 `가수 - 제목` 형태일 때 나눠서 씁니다. 컨트롤·목록·설정이 열려 있으면 숨깁니다.
- **긴 문장 줄바꿈**: 안드로이드 기본 줄바꿈은 한글 단어 중간에서도 끊어서, **띄어쓰기에서만** 줄을 나눕니다. 길면 줄 수는 가장 적게 잡고 그 안에서 줄 폭을 균형 있게 맞추며, 그래도 안 들어가면 글자 크기를 줄입니다.
- **프레임 표시 기본 꺼짐**(설정에서 켤 수 있음).

## 4. 박스에서 시험할 것 (시험판 체크리스트)
설정에서 **프레임 표시**를 켜면 화면 왼쪽 위에 `720p · 30 fps` 같은 숫자가 나옵니다(기본은 꺼짐).
1. **프레임**: 기본(720p)에서 30fps 가 유지되는지. 설정 → "그리는 해상도"로 **1080p**와 비교.
2. **소리**: 끓거나 끊기지 않는지(특히 무거운 배경이 나올 때).
3. **배경별 프레임**: 프레임 표시를 켜고, 곡을 넘기며 fps 가 떨어지는 배경이 있으면 이름을 알려 주세요. 설정에서 해당 배경을 끄면 됩니다. 의심 순서: 깊이감 빛 덩어리 > 떠다니는 빛 덩어리 · 오로라 · 안개 · 흐르는 그라데이션 · 지나가는 빛줄기 > 나머지.
4. **줄 바뀜**: 가사가 바뀔 때 잠깐 멈칫하는지(다음 줄을 미리 만들어 두지만 아주 긴 줄은 시간이 걸릴 수 있음).
5. 글자 크기, 줄 겹침, 강조 장식이 보기 편한지.

## 5. 알아 둘 점 (시험판에서 빠진 것)
- **USB 직접 접근(libaums) 2단계는 없습니다.** 안드로이드가 마운트한 USB/SD 경로만 읽습니다. 웹뷰 버전에서 1단계로 잘 읽히던 박스라면 그대로 됩니다.
- 앨범 커버, 시크바, 단어별 가사 싱크는 없습니다.
- 해상도를 바꾸면 화면이 잠깐 다시 만들어집니다.
- 실시간 블러·소리 반응 효과는 박스 성능을 알 수 없어 넣지 않았습니다.

## 폴더 구조
```
app/src/main/java/com/lyricplayer/tvn/
  MainActivity   화면 구성, 리모컨 키, 재생(ExoPlayer), USB 검색 호출
  GlRenderer     배경 셰이더 10종 + 가사 그리기(텍스처 사각형), 효과 계산, 다음 줄 미리 만들기
  LineTex        가사 한 줄을 비트맵으로 (글자 맞춤, 강조 장식, 단어/글자 조각 계산)
  Fx             효과 목록, 곡마다 랜덤 선택 규칙
  Wrap           긴 가사 줄바꿈(띄어쓰기에서만, 균형 있게)
  Lrc            LRC 읽기 (UTF-8/EUC-KR, 여러 시간, offset, 단어 태그 제거)
  FileScanner    마운트된 USB/SD 에서 음악·가사 찾기
  Prefs, Track
```
